## Project Description
A Java-based Employee Management System implementing core Object-Oriented Programming (OOP) concepts:
- **Abstraction:** `Employee` abstract class with abstract `earnings()` method.
- **Inheritance:** `HourlyEmployee`, `MonthlyEmployee`, and `CommissionEmployee` extending `Employee`.
- **Polymorphism:** Dynamic salary calculations across different employee types.
- **Encapsulation:** Private attributes with public getters and setters.
- **Association / Aggregation:** `Department` class managing a list of `Employee` objects.
